# Taste News — Startup Introduction Website

A responsive, seven-page static website introducing Taste News and its Smart Thermal Delivery Bag concept.

## Pages
- `index.html` — Home
- `about.html` — About Taste News
- `problem.html` — Delivery challenges
- `innovation.html` — Smart Thermal Delivery Bag concept
- `journey.html` — Intended roadmap
- `team.html` — Team
- `contact.html` — Contact details and email-preparing form

## Preview locally
Open `index.html` in a modern browser. The site uses shared `styles.css` and `script.js`.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site; use the URL shown in Settings → Pages.

## Before publishing
- Replace the temporary text-based TN mark with the official Taste News logo if available.
- Verify all contact details and the Instagram link.
- The contact form opens the visitor's email application; it is not a backend form and does not send automatically.
- The thermal bag is described as a concept under development. Do not represent performance as tested or certified unless that changes and can be substantiated.
- Roadmap dates are intended targets, not completed achievements.

No paid domain or hosting plan is required to try GitHub Pages on a public repository.
